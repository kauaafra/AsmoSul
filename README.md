# AsmoSul

Site da **Asmosul**, a Associação dos Moradores da Quadra 1303 Sul (Arso 131), entidade comunitária que representa os moradores da quadra em Palmas, Tocantins.

O site apresenta o projeto de capacitação da associação e reúne um formulário de cadastro de moradores.

**Acesse:** https://kauaafra.github.io/AsmoSul/

> Este site faz parte de um projeto maior, desenvolvido em conjunto com outras pessoas.

## Funcionalidades

- Página de apresentação do projeto de capacitação: oficinas, cursos e mentorias para os moradores
- Cadastro de moradores dividido em etapas, com dados pessoais, endereço e informações socioeconômicas
- Máscaras de preenchimento para CPF e telefone
- Tela de acesso com usuário e senha

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

```
AsmoSul/
├── index.html      # Página do projeto de capacitação
├── cadastro.html   # Cadastro e acesso de moradores
├── Css/            # Estilos
├── JavaScript/     # Máscaras dos formulários e navegação entre etapas
└── Imagens/        # Logo, fotos e vídeos da associação
```

## Como executar

1. Clone o repositório:
   `git clone https://github.com/kauaafra/AsmoSul.git`
2. Abra o arquivo `index.html` no navegador.

Não é preciso instalar nada: o site é estático.
